# Sonam Tenzin | Personal Portfolio Website

A responsive personal portfolio website built for the assignment
"Personal Portfolio Website Design and Development".

## About

I am a Diploma student in Computer System and Networking at Jigme Namgyal
Engineering College. This site presents my skills, projects, education
and contact details.

## Sections

- Home, About Me, Skills, Projects, Education, Contact

## Features

- Responsive layout for desktop, tablet and mobile
- Dark and light theme toggle (choice is saved in the browser)
- Mobile navigation menu
- Accessible markup with keyboard support

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- JavaScript (vanilla)

## Project Structure

    my_portfolio/
    ├── css/style.css
    ├── images/profile.jpg
    ├── js/script.js
    ├── index.html
    └── README.md

## Run Locally

Open `index.html` in a browser, or use the VS Code Live Server extension.
